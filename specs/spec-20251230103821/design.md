# 设计（design）

## 架构概览
- 前端单页（HTML/CSS/JS）实现，重点在内容排版与阅读体验。
- 页面结构包含：标题区、正文区、作者/日期信息、推荐阅读区。

## 关键流程/时序
1) 用户访问页面 → 展示文章摘要与正文内容。
2) 用户滚动阅读 → 目录高亮或返回顶部按钮（可选）。
3) 用户阅读完成 → 推荐阅读模块展示。
