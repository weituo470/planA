# 设计（design）

## 架构概览
开发一个技术博客网站，支持文章发布与管理、分类/标签与搜索、Markdown编辑、响应式阅读体验，并提供阅读数据面板以评估内容效果，满足访客与作者的核心使用场景与验收标准。

## 关键流程/时序
1) 访客浏览：进入首页查看最新文章列表（标题/摘要/发布日期）→ 按分类/标签筛选 → 进入文章详情查看正文/作者/发布日期及上一篇/下一篇
2) 访客搜索：输入关键词并搜索 → 返回标题或正文匹配的文章列表 → 进入文章详情
3) 作者内容管理：创建文章 → 使用Markdown编写 → 保存草稿（未发布仅作者可见）→ 发布（对访客可见）→ 编辑已发布文章并保存（内容更新且保留原发布日期）→ 下线
4) 作者数据查看：进入数据面板 → 查看每篇文章阅读量与近7天趋势
5) 跨端阅读：移动端/桌面端访问文章页 → 自适应布局确保正文可读性

## 实现考虑
- 内容模型需包含状态（草稿/已发布/下线）、分类、标签、作者、发布日期、摘要与正文
- 搜索需覆盖标题与正文，支持关键词匹配与结果列表展示
- 发布/编辑规则：发布后保留原发布日期，仅内容更新；草稿仅作者可见
- 文章详情需提供上一篇/下一篇导航，按发布时间或序列排序
- 响应式布局需保证移动端正文排版与可读性
- 统计口径明确阅读量定义与近7天趋势计算方式
