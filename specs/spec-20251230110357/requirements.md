# 需求（requirements）

## 背景
<think>**Requesting clarification with concise questions**</think>

为了写网页，我需要一些细节。你可以用纯文本或 JSON 回答这些问题：

1) 网站类型与目标？（例如：产品展示、个人主页、活动宣传）
2) 目标用户与主要动作？（例如：了解产品、报名、下载）
3) 内容与板块？（例如：Hero、功能、定价、FAQ、联系）
4) 视觉风格与参考？（例如：简洁、科技感；如有链接可给）
5) 语言与品牌元素？（中文/中英、LOGO/配色/字体）
6) 是否需要表单或交互？（例如：订阅、留言、按钮跳转）
7) 技术偏好？（纯 HTML/CSS/JS 或 React 等；是否需响应式）

## 用户故事
- 作为用户，我希望能够帮我写个网页，以便获得清晰的内容与体验。

## 验收标准（EARS）
- WHEN 用户打开页面
  THE SYSTEM SHALL 展示与“帮我写个网页”一致的内容布局与样式
- WHEN 用户滚动阅读
  THE SYSTEM SHALL 保持排版清晰、可读性良好
