# 验收标准

## 任务流可视化
- 当任务图更新事件到达时，DAG 必须在 1 秒内刷新。
- 当用户拖拽任务节点后，必须实时同步到服务端。

## 状态流转
- 当触发审批请求时，状态必须切换为 Reviewing。
- 当审批全部完成时，状态必须返回 Thinking。

## Diff 预览
- 当监测到文本文件变更时，必须推送 Diff 预览。
- Diff 需包含文件路径与上下文。

## 需求补丁
- 提交补丁后，事件流必须记录补丁内容。
- 补丁必须在事件列表可追溯。

## 测试报告
- 收到测试报告事件后，必须弹出结果窗口。
- 结果窗口必须提供 Submit 与 Retry 按钮。
